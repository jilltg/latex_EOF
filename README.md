## Louisiana-Texas (LATEX) Bottom Temperature EOF Analysis

Empirical orthogonal function (EOF) analysis of HYCOM-TSIS bottom 
temperature, salinity, and vertical velocity on the Louisiana-Texas 
(LATEX) continental shelf (1996–2022).

## Data
- HYCOM NCODA reanalysis (GOMu0.04, 1996-2012, 1/25° resolution)
- HYCOM TSIS reanalysis (GOMb0.04, 2001-2024, 1/25° resolution)

## Requirements
R 4.x — packages: ggplot2, dplyr, lubridate, foreach, doParallel, cowplot, smoother

## Usage
Set working directory to repo root, then run EOFanalysis.R
